# Retail Integration Patterns Lab

A hands-on retail platform for learning, implementing, testing, and documenting common enterprise integration patterns across local, Azure, and GCP environments.

## Objectives

- Implement at least two integrations for each common integration pattern.
- Compare Spring Boot, Apache Camel, MuleSoft, and cloud-native services.
- Integrate an open-source ERP and synthetic retail data sources.
- Practice APIs, queues, events, webhooks, files, CDC, streaming, and orchestration.
- Document requirements, contracts, mappings, tests, decisions, and runbooks.
